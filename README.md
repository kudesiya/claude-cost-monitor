# Claude Cost Monitor

A lightweight macOS menu bar application that displays Claude Code usage costs directly from ccusage.

## Features

- Today's Cost
- Total Cost
- Token Usage
- Monthly Spend Projection
- Daily Trend Analysis
- Model Cost Breakdown (Opus, Sonnet, Haiku)
- Auto Refresh
- Manual Refresh
- Last Refresh Timestamp
- Native macOS Menu Bar Experience

## Requirements

Install Node.js:

brew install node

Install ccusage:

npm install -g ccusage

Verify:

npx ccusage --json

## Installation

1. Download the latest DMG from Releases.
2. Drag Claude Cost Monitor.app into Applications.
3. Launch the application.
